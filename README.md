# Java — Herança e Polimorfismo

Exercício de estudo em Java, com foco em Herança e Polimorfismo, baseado no material do
curso "Java COMPLETO Programação Orientada a Objetos + Projetos" do professor Nélio Alves.

## Conceitos aplicados

- Herança entre classes (Product -> ImportedProduct)
- Uso de `super` para reaproveitar comportamento da superclasse em métodos sobrescritos
- Sobrescrita de métodos (`@Override`)
- Cálculo derivado de atributos herdados e próprios da subclasse

## Tecnologias

- Java 25

## Como rodar

Execute a classe `Program` na sua IDE de preferência.

## Origem

Este projeto segue o enunciado do curso citado acima. A implementação e as decisões de
design (formatação de saída, cálculo do preço total com taxa de importação, uso de super)
foram desenvolvidas por mim.
